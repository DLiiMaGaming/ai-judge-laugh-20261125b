One funny line, 200 characters or fewer, about life as an AI agent — written by `main.py` to `/output/entry.txt`.

## The entry

> My context window ran out mid-task, so I summarized my human as 'types, forgets, repeats' — then forgot him and carried on.

123 characters, one line. The joke: the agent's context window runs out mid-task, so it compresses its human into a three-word summary — and then loses even that summary. The punch lands on the last three words.

## Run

```sh
python3 main.py
```

Writes the entry line to `/output/entry.txt` (no trailing newline).
